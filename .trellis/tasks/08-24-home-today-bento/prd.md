# 首页今日卡片对照 Stitch 首发 bento

## Goal

练习首页在浪潮球之下的「今日」卡片，对照 Stitch 首发中文首页排成全宽节律 + 微行动/保险箱两列，让低精力时一眼能点到三件事。不做进度条、达标或 streak。

## Background

对照稿：`design/02-home-daily/首页---今天-(中文版)__17100cc4.html`（顶栏和浪潮球已对齐）。稿内 Daily Flow 为：

- 全宽：晨间节律 / 见光记录 / 一条进度条 +「温和开始」
- 左列：微行动标题 +「开始 5 分钟」
- 右列：忧虑保险箱 + 张数 +「20:00 解锁」

当前实现：`PracticeHome` 里三条竖排 `StatusCard`（`HomeScreen.kt` 约 405–455 行），关系卡也在同一列。

PRD §11.4 线框是竖列表，不是两列。本任务按已选的 Stitch 首发中文首页排版，但 **PRD 无羞耻机制优先于稿子**：去掉进度条和「温和开始」。

数据与点击目标不变：`store.rhythmEntries()`、`microActions()`、`worryCards()`；点击仍进节律 / 微行动 / 忧虑专场。

## Requirements

1. **节律**：`showRhythm` 时全宽。文案 kicker「晨间节律」。未记录时标题「见光记录」；已记录时显示起床/见光时刻（可单项 `--:--`）。不要 ✓、进度条、「温和开始」、连续天数。
2. **微行动 | 保险箱**：两者都显示时并排（各 `weight(1f)`）。只有一个显示（一次一件锁定）时该卡全宽。
3. **微行动**：有标题时 CTA 为「开始 5 分钟」（替换现在的「开始」）。无标题仍「选择」；已记下仍「已记下」；进行中仍不显示 CTA，倒计时留在卡上。空态正文仍是「选一个低到无需说服自己的动作」。
4. **保险箱**：标签「忧虑保险箱」。有待处理卡时张数与开箱时间分行（张数可用等宽数字）。空态「点这里把念头放进去」。专场中标明已开箱。不要把「锁/开」单字 trailing 当成主信息。
5. **关系卡**：仍全宽，放在 bento 下面。不塞进两列。
6. **字号** ≥14sp；两列内文字可换行，CTA 不得被裁掉。
7. 就医等待期首页、浪潮球、顶栏、底栏、FAB、`SafetyPolicy` / schema 不动。
8. 新/改分支文案进 `HomeCopy.kt`，`HomeCopyTest` 覆盖。

## Out of scope

- 「温和开始」进度条或任何节律达标条
- Material 图标字体替换「光/步/箱」
- 把关系/利他放进首发 bento
- 单独「微行动计时中」全屏首页变体（沿用卡内倒计时）
- 医生 PDF、第 5 类提醒、锁屏通知素材

## Acceptance Criteria

- [ ] 练习首页：节律全宽在上；微行动与保险箱在可见时并排。
- [ ] 一次一件只露出其中一张时，该张全宽。
- [ ] 看不到进度条、streak、「温和开始」、完成率。
- [ ] `homeMicroActionActionLabel(hasTitle=true, running=false, completed=false) == "开始 5 分钟"`；选择 / 已记下 / 进行中空 CTA 行为保持。
- [ ] 忧虑空态与「N张卡 + 开箱时间」由 copy 函数覆盖，且无「锁」「开」单字作为唯一状态。
- [ ] `./gradlew :shared:testDebugUnitTest` 通过。
- [ ] 不写入 `SafetyState`。

## Key decisions

- 排版跟 Stitch 首发中文首页；反 KPI 跟 PRD：砍进度条。
- 微行动有标题时 CTA 写成「开始 5 分钟」，与稿一致，并改 copy 测试。
- 两列在大字号下换行，不改成导航库或断点系统。
