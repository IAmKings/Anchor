# 就医等待期首页对照 Stitch 中文稿

## Goal

让 `MedicalWaitingHome` 的层次和说明更接近 Stitch 首发中文就医等待期首页，同时守住 CONTEXT / PRD：暂停不是惩罚，双栏仍是事实记录。

## Background

对照稿：`design/02-home-daily/首页---就医等待期模式-(中文版)__b7b22d9f.html`。结构已经对上：徽章 + 标题、专业支持卡、可用工具列表。差在徽章用词、说明正文、工具卡副文案。

权威文案：

- CONTEXT：**就医等待期**（Avoid：禁用模式、锁定）。「屏蔽是防止过度自我要求，不是惩罚」。
- PRD §10.2 / FR-7.7：「暂停练习不是惩罚，是防止你在未获专业支持时过度自我要求。」
- 现首页：徽章「医疗等待期」；正文把 PRD 句和「指南/清单/双栏仍可用」拼在一起。
- 稿子说明：「由于你当前的状态，练习已暂时停用。这并非惩罚……避免过度消耗。请将精力集中在寻求专业帮助和基础休养上。」
- 稿子事实记录：「记录此刻的感受」——和 CONTEXT 双栏「摄像头能拍到的事实」冲突，不用。

`OnboardingCopy.medicalWaitingBody` 给评估结果页，本任务不改，避免两处产品句分叉。

## Requirements

1. 徽章改为「就医等待期」，不用「医疗等待期」。
2. 标题保持「休息即是当下的练习」。
3. 说明必须包含 PRD 原句「暂停练习不是惩罚，是防止你在未获专业支持时过度自我要求。」可加一句「请把力气放在寻求专业帮助和基础休养上。」不要用稿子的「感受 / 过度消耗」替代 PRD 句。
4. 专业支持卡：标题、副文案、「查看就医指南」按钮保持；仍进指南，不改热线。
5. 工具卡：
   - 就医准备清单：可用稿「为下一次医生问诊做准备，记录近期的身体感受。」（清单本就是躯体。）
   - 事实记录：**必须**「记录此刻能被看见的事实，暂不进行分析。」禁止「感受」。
   - 「再次评估」在 `canReassessNow` 时保留，稿子没有也不删。
6. 文案进 `HomeCopy.kt`，`HomeCopyTest` 覆盖徽章、说明含 PRD 原句、事实记录副文案不含「感受」。
7. 字号 ≥14sp。不改浪潮球、练习 bento、FAB「助」、底栏、`SafetyPolicy`、schema。

## Out of scope

- 底栏 Material 图标、terracotta 电话 FAB（现有「助」已覆盖求助）
- 改 `OnboardingCopy.medicalWaitingBody` / 评估结果页
- 就医指南热线、地区选择
- 仪器测试隔离

## Acceptance Criteria

- [ ] 徽章为「就医等待期」。
- [ ] 说明包含 PRD §10.2 原句，不含「记录此刻的感受」。
- [ ] 事实记录工具副文案是摄像头事实，不是感受。
- [ ] 清单副文案可写身体感受；再次评估入口仍按 48h 规则出现。
- [ ] `./gradlew :shared:testDebugUnitTest` 通过。
- [ ] 不写入 `SafetyState`。

## Key decisions

- 领域词跟 CONTEXT：就医等待期，不是医疗等待期。
- 惩罚句跟 PRD，不跟 Stitch 改写。
- 双栏副文案跟 CONTEXT，不跟 Stitch「感受」。
