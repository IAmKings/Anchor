# 17 页人工验收脚本

对着 Android Debug 包逐页勾。权威是 [PRD.md](../PRD.md) 与 [CONTEXT.md](../CONTEXT.md)。Stitch 只看版式；稿和产品冲突时 **产品对、稿错**，不要开成缺陷。

安装：`make install-debug` 或 `./gradlew :androidApp:installDebug`。会写进日常库 `anchor.db`。不要和仪器测试混用同一台正在测隔离库的设备。

设置 → 关于 里的预览 **不改真实安全状态 / 记录**（首启评估、回归练习、就医指南、首页回血/抽干/耗竭、危机澄清、一次一件锁定）。

---

## 规则（每页都适用）

- [ ] 主按钮大约 52.dp，用户可见字 ≥14sp，长页能滚
- [ ] 无 streak、完成率、补卡、鸡汤、「必须」
- [ ] 热线来自本机地区资源，不是稿上的「希望24」或写死唯一 120/110
- [ ] 锁屏通知若出现，只显示「锚点」，不显示正文

**不要当成缺陷（全稿通用）**

评估提交中缓冲页、轻度结果里的微行动列表、个性化推荐微行动、忧虑划掉动效、洞察 15%/耗竭率/HRV、医生 PDF、锁屏独立开关、第五类节律提醒、四格身体定位、习惯类锚点（正念呼吸 / 数字睡前）。

建议顺序：波 1 红线 → 波 2 当天 → 波 3 练习 → 波 4 回看 → 波 5 P1。红线不过，后面练习页不必硬过。
