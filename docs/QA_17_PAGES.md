# 17 页人工验收脚本

对着 Android Debug 包逐页勾。权威是 [PRD.md](../PRD.md) 与 [CONTEXT.md](../CONTEXT.md)。Stitch 只看版式；稿和产品冲突时 **产品对、稿错**，不要开成缺陷。

安装：`make install-debug` 或 `./gradlew :androidApp:installDebug`。会写进日常库 `anchor.db`。不要和仪器测试混用同一台正在测隔离库的设备。

渠道：`standard`（GitHub Release 与国内渠道，含 `USE_EXACT_ALARM`）和 `play`（Google Play，不含）。GitHub Release 每版挂两个包，包名带 `-play` 的是 play 渠道。

设置 → 关于 里的预览 **不改真实安全状态 / 记录**（首启评估、回归练习、就医指南、首页回血/抽干/耗竭、危机澄清、一次一件锁定）。
