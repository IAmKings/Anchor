# 纯本地存储，无账号体系，无云端同步

情绪、忧虑、关系记录属于用户最敏感的数据，且本产品信任基础的成立前提是"数据不出设备"。我们决定：全部数据仅存设备本地（加密数据库），无账号、无后端、无云端副本，换机靠用户主动的加密导出文件迁移。

**Status**: accepted

**Considered Options**:
- 本地优先 + 可选端到端加密云同步：被拒。云同步虽解决换机与多设备，但引入密钥管理、账号找回、服务器与合规面；对亚临床调节工具而言收益有限，风险不成比例。
- 纯本地：选中。隐私承诺可对外说死，架构最简，且与"严格零收集"（ADR-0003）互洽。

**Consequences**:
- 产品侧无法获得任何使用数据，目标验证只能定性（见 ADR-0003）。
- 换机依赖用户主动迁移，存在数据丢失风险；接受该代价，以"导出时明示一次性密码与迁移指引"缓解。
- 危机热线号码随应用版本更新，号码失效与商店审核周期之间存在窗口；以"发布前逐条复核（PRD §10.4）+ 危机页保留通用 120/110 引导"缓解，不做网络校验以守住纯本地承诺。
