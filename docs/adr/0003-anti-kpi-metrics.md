# 反 KPI 化指标纪律与严格零收集

心理健康产品的最大自毁方式是"把自我关怀做成新的项目管理"。我们决定：① 产品侧严格零收集——不采集、不上报、不遥测任何使用数据，PRD §3.2 指标仅用户本地自查，产品目标（G1-G5）验证依赖定性手段（应用商店评论、用户访谈、支持邮箱、小样本研究招募）；② 任何新指标进入目标集前必须通过"反 KPI 审查"——回答"优化它会诱导产品做什么行为"，会诱导催促/打卡/放大焦虑的一律降级为护栏或删除。

**Status**: accepted

**Considered Options**:
- 埋点采集定量指标：被拒。即使匿名，采集本身与"数据不出设备"（ADR-0001）承诺冲突，且历史反复证明完成率类指标会反向诱导催促式设计。
- 可选匿名聚合上报：被拒（本轮）。保留为未来候选路径。

**Consequences**:
- 产品方长期缺少定量增长指标，运营以定性反馈驱动；这是有意为之的成本，不是疏漏。
- 未来若确需定量指标，必须走本 ADR 的审查流程重新决策，并单独取得用户明确同意；此约束不可由团队内部自行放宽。
